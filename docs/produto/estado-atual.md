# Estado atual do produto

## Base visual inicial

A base contém uma tela de abertura, início com conteúdo demonstrativo, navegação inferior para início, busca, pedidos e perfil, além de um ponto de entrada visual para a área da empresa.

## Ainda não implementado

Esta entrega não conclui nenhuma das 14 funcionalidades previstas no plano. Cadastro, login, validação de idade, busca e filtros funcionais, catálogo editável, carrinho, endereço, checkout, comprovante, pedidos, histórico, persistência e integração com serviços ainda precisam ser desenvolvidos.

Os textos, estabelecimentos e preços na tela inicial são exemplos estáticos. A seleção de categoria altera somente o estado visual.

A logo do BebidaJá e as imagens de água, refrigerante e suco são recursos visuais locais, sem marcas comerciais.
